# Changelog

All notable changes to EMU will be documented in this file.

## [4.0.2] - 2026-05-24
### Added
- Added `emass upload artifact`

### Changed
- Converted the `contentType` parameter into a map-based `headers` parameter in the `emass.POST` function

### Removed
- Comments that weren't adding value

## [4.0.1] - 2026-05-24
### Added
- `emu test api` subcommand for testing connectivity to the eMASS API
- Replaced `Vic Fernandez III` with `Victor Fernandez III` throughout

## [4.0.0] - 2026-04-23
### Added
- Initial v4 release

### Changed
- Migrated from v3 configuration format
