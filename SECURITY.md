# Security Policy

## Security Advisories

Security advisories use the Vulnerability Exploitability eXchange (VEX) standard. This project maintains VEX source data in YAML and generates an OpenVEX document for the dependency vulnerability scanner.

Each advisory identifies a vulnerability, its associated product, its current status, and the rationale for that status. An advisory with a `not_affected` status includes a justification and an impact statement.

For the latest security advisories, refer to [vex.yaml](vex.yaml).

## Reporting a Vulnerability

To report a security issue, use https://github.com/orgs/deathlabs/discussions/new?category=security. We will respond to reports within seven business days.
